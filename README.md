# Фоторадар

Поиск открытых заявок на съёмку в Екатеринбурге.

Сборщик: GitHub Actions, расписание каждые 10 минут (запуск может задерживаться), также Actions → Фоторадар — сбор объявлений → Run workflow. Кнопка «Найти сейчас» на сайте открывает этот запуск; нужен аккаунт с правом запуска.

Сайт: GitHub Pages, источник публикации GitHub Actions. Вход через ChatGPT не используется. Репозиторий и сайт публичные; случайный адрес и noindex не заменяют авторизацию.

Автоматически проверяются открытые Telegram-каналы, два публичных чата через виджеты сообщений и API «Работа России». Доступность источников показана на сайте. VK и Telegram API включаются только при настройке соответствующих Actions Secrets.

Видимые уведомления о новых заявках работают при открытом сайте после разрешения браузера. Web Push при закрытом сайте требует настройки VAPID_PRIVATE_KEY и PUSH_SUBSCRIPTIONS в Actions Secrets. Секреты и подписки нельзя добавлять в файлы публичного репозитория.

Проверки: python -m unittest test_filter test_sources
