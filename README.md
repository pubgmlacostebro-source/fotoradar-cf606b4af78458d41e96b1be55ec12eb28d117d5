# Никарадар

Поиск открытых заявок на съёмку в Екатеринбурге.

Сборщик: GitHub Actions, расписание каждые 10 минут (запуск может задерживаться), также Actions → Никарадар — сбор объявлений → Run workflow. Кнопка «Найти сейчас» запускает сбор прямо с сайта после подключения Fine-grained GitHub token с доступом Actions: Read and write только к этому репозиторию. Ключ сохраняется локально в этом браузере и отправляется только api.github.com. После закрытия вкладки он восстанавливается автоматически. Кнопка «Забыть ключ» удаляет сохранение; истёкший ключ нужно заменить. Сайт ждёт завершения Actions и появления новой ленты.

Сайт: GitHub Pages, источник публикации GitHub Actions. Вход через ChatGPT не используется. Репозиторий и сайт публичные; случайный адрес и noindex не заменяют авторизацию.

Автоматически проверяются открытые Telegram-каналы, два публичных чата через виджеты сообщений API «Работа России», открытые датированные заказы Профи.ру и открытые страницы вакансий hh.ru. Вакансии отделены от разовых заказов, проверяются адрес Екатеринбурга и дата публикации (72 часа). Доступность источников показана на сайте. VK и Telegram API включаются только при настройке соответствующих Actions Secrets.

Видимые уведомления о новых заявках работают при открытом сайте после разрешения браузера. Web Push при закрытом сайте требует настройки VAPID_PRIVATE_KEY и PUSH_SUBSCRIPTIONS в Actions Secrets. Секреты и подписки нельзя добавлять в файлы публичного репозитория.

Проверки: python test_filter.py; python test_sources.py; node tools/test-run-search.cjs

## География и источники
Никарадар ищет только в Екатеринбурге. Пышма, Берёзовский, Арамиль и другие города не входят в поиск. Для общероссийских каналов город должен быть указан в самом запросе. Локальный канал даёт контекст города, но явное указание другого города исключает объявление. Запросы локаций без поиска фотографа исключаются.
Добавлены публичные ленты photomeetekb, dnevnikactor, normrabota, freelancer_tg и чтение открытых вакансий Зарплата.ру. Недоступность источника показывается на сайте; ноль совпадений не означает ошибку.
